# CF优选IP（域名版）

把 Sub-Store 订阅里走 Cloudflare 的节点地址，统一换成你自己的域名；
最优 IP 每次测出来后，自动写到这个域名的 DNS 记录里。

## 和 IP 版的区别

| | IP 版 | 域名版（本版） |
|---|---|---|
| 节点地址写什么 | 每次测出的最优 IP | 固定不变的域名（如 cf.example.com） |
| 最优 IP 变了以后 | 客户端必须重新拉订阅才拿到新 IP | 不用拉订阅，等 DNS 生效（TTL 60 秒）就连到新 IP |
| 需要什么 | 不需要额外配置 | 需要一个 Cloudflare API 令牌，用来改 DNS 记录 |

两个版本是独立的 app，可以同时装在飞牛上（IP 版默认端口 18088，
域名版默认端口 18089），互不干扰。

## 关键点（缺一不可）

1. **记录必须是“仅 DNS”（灰云），不能开小黄云代理。**
   开了代理，域名解析出来的是 Cloudflare 的任播 IP，
   你填的优选 IP 就白填了。app 写记录时固定传 proxied=false，
   回查发现是代理状态会直接报错提醒。
2. **SNI 必须保留原域名。** 节点原来有 servername/sni 就保留；
   空的就填上原域名；TLS 节点没有的就补一行 servername=原域名。
   否则改了地址会连不上。
3. **TTL 60 秒。** app 写记录时用 TTL 60，API 不接受时自动退回“自动”，
   并在状态里说明。

## 登录（1.0.17 起；1.0.18 起账号设置移到右上角，可改账号）

设置页需要登录才能打开，默认账号 `admin`、默认密码 `admin`。
首次登录后，请点设置页右上角的“⚙ 设置”，在“账号设置”里改
账号和密码（新密码至少 4 位；只填新账号就是只改账号，只填
新密码就是只改密码）；改完后其它设备/浏览器上的登录会失效，
要用新账号密码重新登录，当前这个浏览器保持登录。会话有效期 30 天。

忘记密码：删掉本机数据目录 `config.json` 里的 `auth` 一段，
重启应用即恢复默认 `admin` / `admin`。

订阅链接（`/sub/<名字>`）不需要登录，代理客户端拉订阅时
本来就登不了，所以这部分一直公开；要登录的只是设置页和
管理接口。

## 安装后要做的事

1. 在飞牛应用中心本地安装本 fpk，端口默认 18089
   （安装向导里的服务端口和测速间隔已预填默认值，直接点下一步即可；
   向导里改了端口，桌面图标仍指向 18089，请用 http://NAS-IP:新端口 打开）。
2. 打开设置页（先用默认账号 admin / admin 登录），在“域名绑定”里填：
   - API 令牌：Cloudflare 后台 → My Profile → API Tokens，
     用“Edit zone DNS”模板，只给这一个 Zone 的权限。
     令牌只存在 NAS 本机，页面和状态接口永远不会把它显示出来。
   - 域名：顶级域名，如 example.com（该域名的 DNS 须托管在 Cloudflare）。
   - 记录名：前缀，如 cf，最终域名就是 cf.example.com。
3. 点“立即更新 DNS 记录”，看到成功，再把 app 链接换到客户端。
4. 在设置页添加 Sub-Store 下载链接，点“立即测速并更新”，
   app 会测速、更新 DNS 记录、生成订阅。
5. 客户端用 app 给的 /sub/<名字> 链接。以后最优 IP 再变，
   不用动客户端，等 DNS 生效即可。

## 1.0.22 新功能

### 在线升级

设置页新增“在线升级”卡片：点“检查更新”会从公开仓库
liweisi07/cf-bestip-fpk 的 manifest 读最新版本号和更新日志，
有新版时显示更新日志并提供“下载 .fpk”按钮，下载到本机数据
目录的 `updates/` 文件夹；下载后在飞牛应用中心本地安装这个
.fpk 即可（直接覆盖安装，配置保留）。不会自动安装，下载前
不会动现有应用。fnOS 没有官方支持的“应用内自升级”接口，
所以下载 + 手动安装就是本功能的完整范围。

### 通知（Telegram / 飞书）

设置页新增“通知设置”卡片，两个渠道各自独立开关：

- **Telegram**：填 Bot Token 和 Chat ID。注意 Telegram 在国内
  直连不通，须在“代理”栏填一个能访问 api.telegram.org 的代理
  （如本机 Clash 的混合代理 http://127.0.0.1:7890）。
- **飞书**：填群机器人的 incoming webhook 地址，可选填加签密钥。

默认开启的只有三类故障：测不到 IP、域名异常、断网。
断网时发不出去，所以断网通知是在恢复后补发的，会写明断网
时段（从 X 到 Y）和“网络已恢复”；短于 60 秒的闪断不通知。
同类故障只在第一次出现时发一次（去重），持续失败时每 24 小时
提醒一次，直到恢复。另有两类可选事件（默认关闭）：
成功换 IP、日常测速结果，各有一个独立开关。
每个渠道都有“发送测试通知”按钮，点一下就知道配没配通。
Token 和密钥只存在本机，日志里永远不会出现。

### IPv6 优选

设置页“测速计划”里新增 IPv6 开关（默认关闭）。开启后，
每次测速除了 IPv4，还会测 Cloudflare IPv6 地址段（内置的
精选子网列表，官方大段不适合直接测），按同一地区筛选出最优
IPv6，自动把绑定域名的 AAAA 记录指过去，与 A 记录并行更新。
IPv4 与 IPv6 各自独立优选、各自更新，IPv6 测不到或 DNS 更新
失败时按故障规则通知，但不影响 IPv4 的正常流程。
需要本机有 IPv6 出口；没有 IPv6 路由时本次跳过并在日志里写明。

### DNS 一次写前 5 条最优 IP

更新 DNS 时不再只写一条最优 IP，而是把同区域测速排前 5 的
最优 IP 一次写成多条 A 记录（同一域名下多条记录，冗余和分流）。
设置页“域名绑定”里有数量选项（1–5，默认 5）。更新时先清理
掉该域名下旧的、由本应用管理的记录，再写入新集合，不会越积
越多。IPv6 开启时，AAAA 记录也按同一数量写入。
成功换 IP 的通知里会列出这几条 IP。

### 单包双架构

1.0.22 起只打一个 .fpk，同时适配 ARM64 和 x86_64 两种飞牛设备，
文件名不再带 -arm64 后缀。包里同时内置 arm64 和 amd64 两种
cfst 二进制，运行时检测主机架构自动选用对应的那一个；
检测不到的架构会明确报错，不会静默用错。manifest 声明
platform=all，两种设备都可安装。

## 测速计划（1.0.16 起）

设置页“测速计划”有两种模式：

- **每隔一段时间**：和 1.0.15 一样，天/小时/分钟三个框自由填，
  总间隔最短 5 分钟、最长 30 天；手动测速会重置计时。
- **每天固定时间**：每天到设定时间跑一次，如 03:00。
  手动测速不影响定时，到了设定时间照常跑；同一天定时只跑一次。
  时间按 24 小时制填 HH:MM（00:00–23:59）。

**优选地区**：测速仍全量测，挑最优时只在所选地区里按
丢包率→延迟→速度挑（香港 HKG、新加坡 SIN、东京 NRT、首尔 ICN、
洛杉矶 LAX、圣何塞 SJC、法兰克福 FRA，或全部自动）。
该地区没有可用 IP 时用全局最优，并在日志里写明；
结果页会显示本次用的地区，退回全局时也会注明。

## 测速间隔（1.0.15 起）

设置页“测速间隔”里天、小时、分钟三个框自由填，三项加起来算
总间隔：默认 7 天 0 小时 0 分钟；想每小时测一次就填 0 天 1 小时
0 分钟；想每 6 分钟测一次就填 0 天 0 小时 6 分钟。
总间隔最短 5 分钟、最长 30 天，超出范围保存时会报错、不改配置。
手动点“立即测速并更新”会重置计时，下一次按新间隔从这次算起。
从旧版升级上来只填过天数的，小时和分钟默认 0，原间隔不变。

## DNS 更新失败怎么办

定时任务里 DNS 更新失败不是致命错误：记录里留的是上一次的最优 IP，
仍然是能用的 Cloudflare IP，只是可能不是最新的最优 IP；
状态页会显示失败原因，修好后点“立即更新 DNS 记录”即可。
如果域名绑定根本没配置，订阅会原样输出（不改写），
客户端继续用原来的节点地址，不会断网。

## 本地文件说明

- `app/app.py`：设置页 + 订阅服务 + 定时任务 + 登录鉴权。
- `app/cfdns.py`：Cloudflare DNS API 客户端（只用标准库），
  支持多条 A / AAAA 记录的集合写入。
- `app/rewriter.py`：只改 proxies 段的 server 行，其余行逐字节保留。
- `app/cfst.py`：跑 CloudflareSpeedTest 并按丢包→延迟→速度挑最优 IP。
- `app/notify.py`：Telegram 与飞书通知发送（只用标准库）。
- `app/upgrade.py`：在线升级检查与 .fpk 下载（只用标准库）。
- `app/ip6.txt`：IPv6 测速用的精选地址段列表。
- `tests/`：改写、DNS API（模拟）、测速解析、登录、服务端端到端、
  通知、升级检查、双架构选择、IPv6 端到端测试。
- `scripts/make_icons.py`：从 `icon-work/` 里的源图重新生成四个图标
  （ICON.PNG、ICON_256.PNG、app/ui/images/icon_64.png、
  app/ui/images/icon_256.png）。

## 安全提醒

设置页和订阅链接只在家里局域网内用，不要把端口映射到公网，
也不要把 app 的订阅链接外发给别人。设置页有账号密码登录，
但它仍然只是一层局域网内的口令，不是公网防护。
